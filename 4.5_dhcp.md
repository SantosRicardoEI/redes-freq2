# DHCP — Dynamic Host Configuration Protocol — Resumo

## 1. O que é e para que serve

**DHCP (Dynamic Host Configuration Protocol)** permite a um host **obter o seu endereço IP automaticamente** a partir de um servidor, **quando se junta à rede**.

É a alternativa "plug-and-play" à configuração manual (estática) do endereço.

Vantagens:

- **Plug-and-play**: o host liga-se e fica logo configurado, sem intervenção do utilizador.
- **Reutilização de endereços**: o host só fica com o endereço enquanto está ligado; quando sai, o endereço pode ser dado a outro.
- **Renovação**: o host pode renovar a reserva do endereço que está a usar.
- Bom para utilizadores que entram e saem da rede (ex.: portáteis, telemóveis).

---

## 2. As 4 mensagens do DHCP

A interação cliente↔servidor tem quatro mensagens (todas em **broadcast**):

1. **DHCP Discover** — o host novo difunde: *"Há algum servidor DHCP por aí?"*
2. **DHCP Offer** — o servidor responde: *"Eu sou um servidor DHCP! Eis um endereço que podes usar."*
3. **DHCP Request** — o host pede: *"OK, eu fico com esse endereço IP!"*
4. **DHCP ACK** — o servidor confirma: *"OK, o endereço é teu!"*

Decorar a ordem: **Discover → Offer → Request → ACK** ("D-O-R-A").

Nota (RFC 2131): os **2 primeiros passos podem ser saltados** se o cliente se lembra de um endereço que já usou e o quer reutilizar — vai direto ao Request.

---

## 3. O DHCP devolve mais do que o endereço IP

Além do endereço IP atribuído na sub-rede, o servidor DHCP pode devolver:

- O **endereço do router do "primeiro salto"** (gateway por defeito) para o cliente.
- O **nome e endereço IP do servidor DNS**.
- A **máscara de rede** (que indica a parte "rede" vs a parte "host" do endereço).

Ou seja, o DHCP entrega praticamente toda a configuração de rede de que o host precisa.

---

## 4. Onde está o servidor DHCP

Tipicamente, o **servidor DHCP está incorporado no router**, servindo todas as sub-redes a que o router está ligado.

---

## Ideia final

O DHCP dá a um host, automaticamente e ao juntar-se à rede, o seu endereço IP (plug-and-play, com reutilização e renovação). Funciona com 4 mensagens em broadcast — Discover, Offer, Request, ACK — e devolve, além do IP, a máscara de rede, o gateway por defeito e o servidor DNS. Costuma estar integrado no router.
